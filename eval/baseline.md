## 怎么复现

1. `.env` 里填 `BASE_URL`、`API_KEY`、`MODEL=hy3`（或任何 OpenAI 兼容端点）。
2. `npm run eval:check`：不需要 Key，确认 20 个任务的初始状态都会**断言失败**。
3. 连续跑 6 次 `npm run eval -- --jobs 4`；每次结果写入 `eval/results/<时间戳>.json`。
4. `npm run eval:summary` 汇总最近几轮完整评测的中位数。

## 口径

- **一次请求** = 一次 `llm.chat()` 调用；**一次工具调用** = 真正执行的工具。被预算或取消拦下、只写了 `ERROR: not run` 的调用不计入。
- token 全部来自端点返回的 `usage`；6 轮都没有缺失，所以合计是精确值。缺失时汇总会写 `at least` 并单列未知数量。
- 墙钟是 4 并发下的实际耗时；「任务耗时合计」是每个任务耗时相加，两者不能直接比较。
- 通过率是 119/120 个任务尝试，不是「6 轮全部满分」。单轮 20/20 不能外推成长期稳定性。
