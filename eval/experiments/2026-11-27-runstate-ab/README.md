# RunState 拆分 A/B 对照（2026-11-27）

验证 `refactor(core): move RunState and usage types out of Agent` 是否改变 Agent 行为、成本或稳定性。

## 方法

| 项目 | 值 |
| --- | --- |
| 实验因素 | `agent-runtime`（只允许运行时代码变化） |
| A（基线） | `3dc13b6`（main，RunState 仍在 `agent.ts`） |
| B（候选） | `8e19b02`（`refactor/run-state-split-2026-11-27`） |
| 套件 / 模型 | `2026-11-27-eval-system-v6` / `hy3` |
| 任务数 / 并发 | 22 / 1（A/B 默认串行，避免并发时序偏差） |
| 轮次 | 3 轮，每轮 A、B 各跑一遍，交替先后顺序 |
| 命令 | `npm run eval:ab -- --a-dir <A> --b-dir <B> --factor agent-runtime --rounds 3 --jobs 1` |
| 运行时间 | 2026-11-27 22:56–23:34（东八区） |

A/B 执行器核对了套件、模型、端点、并发、任务集指纹、提示词与工具定义指纹、评测执行器指纹和两侧运行环境；两侧工作区均干净，三轮全部 `comparable`，`decisionReady: true`。

## 结果

| 轮次 | A 通过 | B 通过 |
| --- | ---: | ---: |
| 第 1 轮 | 21/22 | 21/22 |
| 第 2 轮 | 20/22 | 21/22 |
| 第 3 轮 | 22/22 | 22/22 |
| **合计** | **63/66** | **64/66** |

- 通过率中位数差值：**0 百分点**；改进的任务-轮次 2 个（`04-create-doc` 第 1 轮、`21-long-context-compaction` 第 2 轮），回归 1 个（`08-extract-duplication` 第 1 轮），其余 63 个任务-轮次同状态。
- 中位数差值（B − A）：业务请求 **+6**、工具调用 +3、输入 Token **+29,603**、输出 Token −472、总 Token **+29,294**、缓存命中 +35,584、墙钟 **−19.1 秒**。
- 费用：无价格表，`cost` 为 `unknown`，不能由 Token 换算。

## 判读

- 这是纯职责迁移，A/B 的通过率中位数差值为 0；单任务的 2 次改进与 1 次回归都属于真实模型的单轮波动（同套件三轮基线本身在 20–22/22 之间波动），没有证据表明拆分改变了能力或失败语义。
- Token / 请求数的中位数变化落在同一套件三轮基线的波动范围内（v6 基线单轮总 Token 637,964–706,678），不能归因于拆分；墙钟差异同理。
- 结论：**不构成能力回归，接受该重构**。
