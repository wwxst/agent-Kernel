## 决定：本轮不补的项（2026-11-11）

按「先不扩能力面」的口径，以下**暂不做**，不是遗漏：

| 项 | 归类 |
| --- | --- |
| MCP | 能力扩张 |
| 网络工具（WebSearch/WebFetch） | 能力扩张 |
| 子 agent | 能力扩张 |
| 记忆（auto memory / 自动注入） | 能力扩张 |
| 会话恢复（`--resume` / `--continue`） | 判定为跨会话留存，与记忆同类，先不做 |
| 上下文压缩 | 依赖会话结构，随之推迟 |
| 云端任务、多形态（IDE/Web/桌面） | 能力扩张 |
| 插件 / skills / hooks | 扩展机制 |

**仍在做**：错误与恢复（超时不再毁掉整轮 ✅）、输入与编辑、渲染、工具细节、权限规则、命令。

## 汇总 A：他们有、我们没有（按影响排序）

### 硬缺口（影响能不能用）

1. **不读项目指令文件**（`AGENTS.md` / `CLAUDE.md`）——两家都靠它注入项目规范；我们现在每轮靠用户口头交代
2. **不能恢复会话**——退出即丢，长任务无法中断再续
3. **没有上下文压缩**——对话一长就撞 token 上限
4. **没有网络工具**（WebSearch / WebFetch）——查资料只能靠用户粘贴
5. **没有 MCP**——接不了外部系统
6. **没有细粒度权限规则**——只能整体切模式，不能「只允许 `git status`」

### 体验缺口

7. 没有 `@` 文件引用、没有外部编辑器、不能粘贴图片
8. 只有单行输入
9. 没有子 agent、没有待办清单
10. 没有自定义命令 / skills / hooks
11. 不能切模型和推理强度
12. 没有检查点/回滚
13. 工具调用串行（慢）

### 安全缺口

14. 没有沙箱（只有路径守卫）
15. 超时后进程树未确认时终止整个任务（两家是返回错误让模型继续）

## 汇总 B：我们有、他们没有

| 能力 | 说明 |
| --- | --- |
| 老终端粘贴兜底 | 同批多行合并，Claude Code 至今仍会逐行发送 |
| 字形自动降级 + 强制开关 | 两家只用 Unicode，老 conhost 会出方块 |
| `PgUp` 暂停刷新 | 应对「运行中翻不了历史」，Claude Code 只有未解 issue |
| 审批期间撤权复验 | 批准后如果权限被改过，旧批准不生效 |
| 每次 Run 的 token/工具预算 | 两家有预算概念，我们的实现更显式 |
| 失败分类为纯展示事实（`isToolResultFailure`） | 不改工具结果文本，只影响展示 |

## 汇总 C：都有但做法不同（最容易踩坑）

| 项 | Claude Code | 我们 | 风险 |
| --- | --- | --- | --- |
| 审批占用输入区 | 菜单顶掉输入框，草稿保留 | 同（今天才补） | 之前两处路径不一致，主视图漏了 |
| 拒绝的语义 | 带原因 + 让模型换方案 | 同（今天才补） | 之前只有 `ERROR:`，模型重试到烧 token |
| 折叠层级 | 2 层 | 主视图 2 层 / transcript 3 层 | 层级多了符号区分不开 |
| 后台任务 | 有 `BashOutput` / `KillShell` | 只有 pid | 模型得自己查真实 pid |

## 汇总 D：都没有（行业未解）

| 问题 | 现状 |
| --- | --- |
| 运行中往上翻历史 | Claude Code 有 5 个未关 issue，社区用 tmux 绕 |
| 老终端 Unicode 字形 | 两家不处理，出方块 |
| 不支持括号粘贴的终端 | Claude Code 仍会逐行发送，官方没修 |
| 长任务超时后的进程清理 | 都没有完全可靠的跨平台方案 |
