## 决定：本轮不补的项（2026-11-11）

按「先不扩能力面」的口径，以下**暂不做**，不是遗漏：

| 项 | 归类 |
| --- | --- |
| MCP | 能力扩张 |
| 网络工具（WebSearch/WebFetch） | 能力扩张 |
| 子 agent | 能力扩张 |
| 记忆（auto memory / 自动注入） | 能力扩张 |
| 会话恢复（`--resume` / `--continue`） | 判定为跨会话留存，与记忆同类，先不做 |
| 上下文压缩 | 依赖会话结构，随之推迟 |
| 云端任务、多形态（IDE/Web/桌面） | 能力扩张 |
| 插件 / skills / hooks | 扩展机制 |
| 粘贴图片 | 协议级改动。`Message.content` 现在是 `string \| null`，收图要改成多模态 part，连带 5 个源文件、68 处测试断言、三套平台剪贴板代码。端点已验证收图（HTTP 200），但真做之前还要定两件没定的事：图片只带当前轮还是每轮都带（决定长会话会不会被图撑爆），以及超限/处理失败怎么当场拒绝。见下 |

**仍在做**：渲染、权限规则、命令。

**本轮已补**（2026-11-11）：

| 类别 | 补了什么 |
| --- | --- |
| 输入与编辑 | 多行输入（`Shift+Enter` + `Ctrl+J`）、跨进程输入历史、`@` 文件补全、`Ctrl+X Ctrl+E` 外部编辑器。只剩「粘贴图片」，已按上面的理由推迟 |
| 渲染与视图 | 配色方案从「mono/full 一个开关」拆成 `AGENT_TUI_THEME=dark\|light\|ansi`，浅色终端不再把近白灰当正文色；顺手修掉文档里把 transcript 键写成 `Ctrl+E` 的错误（实际是 `Ctrl+T`） |
| 工具细节 | 后台任务的输出读取与收尾（`shell-output` / `shell-kill`）——不算能力扩张，是 `shell` 那半个功能的收尾 |
| 错误与恢复 | 进程树清理失败不再终止整轮，改成返回错误让模型继续 |

### 粘贴图片：查到什么（推迟不等于没做功课）

入口三家一致：拖拽进窗口 / `ctrl+v` 粘贴 / 直接给路径。**输入框里只放 `[Image #1]` 芯片，base64 不进输入框**——几十万字符塞进去就没法编辑了。

两家都做图片预处理：Claude Code 用 sharp 做 resize，超过 2000px 直接拒；Codex 会解析出尺寸并回显 `Received image (1280×720)`。

推迟的直接理由是这两个未关 issue：

- [anthropics/claude-code#13480](https://github.com/anthropics/claude-code/issues/13480)：粘一张超过 2000px 的图 → API 400，而**这张坏图已经留在历史里**，之后每轮都带着它、每轮都 400，会话永久砖掉。
- [anthropics/claude-code#34566](https://github.com/anthropics/claude-code/issues/34566)：图片处理器失败时**静默把未缩放的原图塞进上下文**，攒几张之后同样把会话搞砖。

两条都指向同一件事：**图片必须有像素与字节上限，超限要当场拒绝，处理失败要显式失败**——不能「粘进去发出去」就完事。这一条比协议改动本身更值得先想清楚。

## 汇总 A：他们有、我们没有（按影响排序）

### 硬缺口（影响能不能用）

1. **不读项目指令文件**（`AGENTS.md` / `CLAUDE.md`）——两家都靠它注入项目规范；我们现在每轮靠用户口头交代
2. **不能恢复会话**——退出即丢，长任务无法中断再续
3. **没有上下文压缩**——对话一长就撞 token 上限
4. **没有网络工具**（WebSearch / WebFetch）——查资料只能靠用户粘贴
5. **没有 MCP**——接不了外部系统
6. **没有细粒度权限规则**——只能整体切模式，不能「只允许 `git status`」

### 体验缺口

7. 不能粘贴图片——**已推迟**，不是输入框的事：`Message.content` 目前是纯字符串，要收图得先把消息协议改成多模态（`text` / `image_url` 两种 part），`llm.ts`、`Agent`、TUI 展示、以及所有断言 content 是字符串的用例都要跟着改。端点已验证收图，但超限与失败策略没定之前不做。
8. 没有子 agent、没有待办清单
9. 没有自定义命令 / skills / hooks
10. 不能切模型和推理强度
11. 没有检查点/回滚
12. 工具调用串行（慢）

### 安全缺口

14. 没有沙箱（只有路径守卫）
15. 超时后进程树未确认时终止整个任务（两家是返回错误让模型继续）
