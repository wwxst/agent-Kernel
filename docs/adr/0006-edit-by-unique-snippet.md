# 编辑工具用「唯一命中的原文片段」定位，不用行号

`edit(path, old_string, new_string)` 要求 `old_string` 在文件里恰好出现一次；零次或多次都报错，模型读一遍文件再收窄片段。

理由：行号会随着前面的改动整体漂移，而一次 **Run** 里经常要连续改同一个文件；补丁格式（unified diff）对模型来说上下文太脆、写错的代价太高。原文片段定位对「文件已经被改过」这件事更容忍，模型也更容易根据报错自我纠正。代价是「唯一」这条约束得靠 `ERROR` 文本来教它（[ADR-0002](./0002-fold-tool-failures-into-error-text.md)）。
