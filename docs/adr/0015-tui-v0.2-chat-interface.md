# TUI v0.2：Claude Code 风格的聊天式界面

TUI v0.1 已经能固定输入、显示工具状态和 thinking，但视觉上仍像调试控制台：信息压在左上角、缺少层次、下面大片空白。v0.2 只升级 `--tui` 的呈现与交互，不改 Agent 核心逻辑，也不动 `--repl`。

本 ADR 取代 [ADR-0014](./0014-tui-is-a-lightweight-shell.md) 中关于布局、尺寸和 resize 的具体描述；0014 保留为 v0.1 的历史记录。

## 决定

- **聊天式布局**：顶部是项目名（左）/ model（右）和 workspace 路径；中间是对话视口，用户 `❯`、模型 `✻`、工具 `⋯ → ✓/✗`；底部是权限/统计页脚、分隔线和固定输入行。对话内容贴底排列，消息少时从输入区上方开始，不在底部留下大片空白。
- **保留整帧重绘**：v0.1 已经证明它能在传统 Windows conhost 上工作；v0.2 继续用绝对光标定位，不切 alternate screen、不引 TUI 库。底部留 2~3 行缓冲，页脚放在输入分隔线上方，避免 conhost 的窗口底边吃掉状态信息。
- **颜色与字形降级**：优先 256 色，能力不足时退回 16 色；`NO_COLOR` / `TERM=dumb` 时完全不着色。Windows Terminal / VS Code / Linux 用 `❯ ✻ ⋯ ✓ ✗ ─ ↑`；传统 Windows conhost 的默认字体缺少这些字形，自动退成 `> * ... + x - ^`，不把方框字符画到屏幕上。
- **历史滚动**：PageUp / PageDown 查看之前的对话；页脚显示 `↑ N lines`（conhost 为 `^ N lines`）。滚动只改视口，不改输入行；发送新任务时回到最新。
- **窗口 resize**：监听 stdout 的 resize 事件，重新计算标题、对话视口、输入行和页脚，并保留正在编辑的输入行。
- **工具状态**：调用开始显示运行中，结果到达时原地替换成成功/失败，不再追加一条重复记录；权限拒绝保留完整原因。
- **Thinking**：每次模型请求发出后显示 `✻ thinking...`；第一段正文、工具调用或错误到达时重绘掉。
- **审批不削弱**：shell 审批仍然完整展示命令和实际 cwd，y/N 仍在固定输入行读取；无 TTY、EOF、取消、已有排队输入都按拒绝处理。
- **明确不做**：鼠标、多行输入、工具调用详情展开、`/` 命令选择菜单、Hooks、多面板。这些留给日常使用顺手之后。

## 为什么

v0.1 的功能已经够用，问题在「读起来像日志」而不是「像在对话」。把项目、模型、路径分层，把工具结果从追加改成原地替换，再用颜色区分用户/模型/成功/失败，能显著降低扫视成本，而不需要引入 UI 框架。

继续用整帧重绘而不是全屏框架，是因为它已经在 conhost 上验证过、代码量可控，而且失败模式是「显示不好看」而不是「Agent 不工作」。颜色和字形必须是可降级的：同一个二进制要在 Windows Terminal、传统 conhost、Linux xterm 和 CI 管道里都能运行。

页脚放在输入分隔线上方，而不是参考图里的下方：conhost 的最后 1~3 行经常被窗口边框/滚动条吃掉，放在下方会直接消失。这是一个面向兼容性的取舍，不是视觉偏好。

## 代价与边界

- 整帧重绘在慢终端上可能闪烁；流式增量按 40ms 限频。
- 只保留最后一屏，不提供完整历史回滚；Transcript 仍完整保存在 Agent 里。
- 固定布局要求至少 10 行、30 列；resize 会重新排版，但不会把旧消息重新换行成新的历史流。
- 宽度按近似显示宽度换行（CJK / emoji 按 2 列，组合字符按 0 列），不做完整 Unicode East Asian Width 表；长行硬换行，不做横向滚动。
- 传统 conhost 的字形和颜色能力更保守；更好的体验仍建议 Windows Terminal + Cascadia Mono 14~16 号字体。
- 没有鼠标、多行输入、工具详情展开、`/` 菜单、Hooks；这些不是 v0.2 的验收范围。
- 审批的「允许一次」仍然只放行当前这一条命令；这不是沙箱（[ADR-0013](./0013-permission-is-a-policy-not-a-sandbox.md)）。

## 不变量

- **输入区必须在底部**：固定布局下输入行在页脚/分隔线下方，底部留缓冲；回复只改变它上方的对话视口。
- **审批安全不因 UI 改动而削弱**：完整命令、实际 cwd、y/N 读取、默认拒绝和取消链保持原样。
- **Run log 永远不回灌给模型**：它不是 Transcript，删掉它不会改变任何一轮请求。
- **Thinking 只表示等待**：第一段输出、工具调用、错误或取消都会清掉；不能把它当成「请求成功」。
- **颜色/字形可以缺失**：无颜色、无 Unicode 字形、窄终端、resize 都不能让 TUI 崩溃或吞掉审批。
- **TUI 不改变 Agent 决策**：`onToolCall` / `onRequestStart` 只用于显示；循环、预算、消息配对和权限检查点保持原样。
- **退出必须把终端交还 shell**：清掉定时器、键盘/ resize 监听，关闭 readline，从最后一行下方换行；不切 alternate screen。
