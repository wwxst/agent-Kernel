# ADR-0031　每一步只向模型提供可执行的工具

最后一个 Step 收到的工具调用无法再交给模型验证。工具次数用尽时，新调用也必然被拒。如果仍把说明书放进请求，模型可能在最后的回答机会里索要工具，大工具表还可能挤掉回答所需的上下文。

Core 在每个 Step 开头确定一次工具表，供窗口测量、压缩和该步所有业务请求共用。最后一步或已用完工具额度时，模型可阅读已有结果并给出文字答复。进程树清理未确认时，同样使用空工具表，其限制持续至 Session 结束。

这个选择的代价是收尾时模型只能从历史中了解先前操作的细节。请求层省略工具字段，执行层仍独立校验步数与整批预算。即使服务返回了违规调用，每个调用也有配对结果。下一次 Run 重新取得自己的步数和工具额度。
