# 这是 Trusted Local Coding Agent，不是沙箱

`WORKDIR` 只是相对路径的默认基准，不构成任何访问边界：绝对路径、`cd ..`、其他磁盘都能用，子进程的读写权限和启动它的人一样。agent-Kernel 只有完全访问一种模式（[ADR-0019](./0019-full-access-is-the-only-mode.md)），它取消的是 agent 自己施加的限制，不是操作系统隔离。

选择：把它定位成「在你自己的机器、你自己的项目里跑」的单人工具。真实路径解析、输出上限、超时与进程清理，拦的是意外和资源失控，不是恶意代码 —— 所以它们值得做，但不能拿它们当安全保证。真要隔离，方式是用容器、虚拟机、独立用户或只读挂载去跑它，而不是继续往这里的字符串校验上加判断。

代价：这个 agent 不适合跑不受信任的仓库或不可信的 prompt 注入内容。换来的是一条说得清的边界，而不是一份「看起来安全」的检查清单。
