# 沙箱边界靠「遍历工作区」保证，不靠模式展开

`glob` 不调用 `fs.glob`：它自己遍历工作区，再用 `*` / `**` / `?` 去匹配相对路径。

理由：任何「由模式生成路径」的语法都是一块新的逃逸面 —— 花括号展开会把 `{../outside,src}/**/*.ts` 变成两条模式，`..` 藏在片段里、没被切出来就漏了；靠枚举黑名单去堵，漏一个就是缺口。「只遍历工作区里的目录」从结构上就走不出去，不依赖我们把语法列全。代价是只支持三种通配（`{}`、`[]` 按字面匹配）、多二十行实现、大仓库下比原生 glob 慢一点；换来的是边界由结构保证，而不是由检查清单保证。
