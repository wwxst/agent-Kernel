# 2026-11-14 全量审查的防复发记录

本轮保持完全访问、串行工具、零运行时依赖和主屏追加。逐项位置与红绿证据见 [总报告](../reports/2026-11-14-systematic-audit.md) 及模块报告。

| 现象 | 根因 | 解法 | 防复发 |
| --- | --- | --- | --- |
| 普通 glob 能把主线程卡住，取消也无响应 | 多段通配符编译为回溯正则，扫描数量不能限制单次匹配时间 | 用可达位置动态规划匹配，保留原遍历和结果预算 | workspace 的重复通配符子进程截止时间回归及模式语义比较 |
| 后台输出等待忽略取消，日志丢失却说没有新输出 | 轮询缺 signal 检查，stat 异常折成大小0 | 轮询响应取消，真实读取失败传播异常 | workspace 的取消等待、删除真实日志回归 |
| 评测没执行完、没保存成绩，却仍给成功信号 | 并发数未校验，只信 total，写入异步报错未改退出码 | 启动前校验，核对完整任务集合/计数，等待成绩保存 | eval 的非法并发/轮数、缺失/重复/null 结果、保存失败回归 |
| 特殊文件名从诊断记录消失，文件增长绕过读入量约束 | 普通对象原型键与文件名冲突；stat 后全量 readFile | 无原型字典、同句柄有界读取与降级覆盖说明 | diagnostics 的 __proto__ 新增/修改、大文件降级用例；竞态性质另做静态复核 |
| HTTP鉴权错被当网络重试，SSE坏角色/冲突终态被放过 | 错误正文覆盖状态码，拼装时丢弃协议事实 | 保留已确认状态，拒绝非法角色和冲突终态 | llm 本地HTTP断流、角色与终态回归 |
| 修改AGENTS后下一请求仍旧规范，少量输出却先读完整大文件 | 提示函数闭包缓存旧正文；输出截断替代实际读取预算 | 每请求重读、8MiB字节窗口与32000字符双上限 | 真CLI子进程的更新后请求体检查、字节窗口测试；ADR-0022 |
| 读取工具定义能改写校验规则；Hook断言失败却不红 | 嵌套Schema共享引用；断言放进有意隔离异常的Hook里 | 说明书深拷贝，测试回调只收上下文、回调外断言 | registry公开接口回归、错误期望值敏感性实验 |
| 已完成详情打不开，主视图丢截断/未知状态提示 | 已打印主屏守卫误用到transcript，概览省略完整性信息 | 独立详情折叠状态，保留真实尾注与未返回状态 | TUI完成轮次详情/折叠、截断/未知结果回归 |
| 长/多行输入光标错位、暂停时打字不可见、文件候选无法选择 | 输入显示和光标使用不同起点；暂停拦截用户重绘；菜单选择只处理slash | 共用可见段边界、用户输入强制刷新、共用候选选择 | TUI公开键盘输入与可观察光标、菜单回归；真实IME仍待验 |
| 编辑器临时路径带空格失效，可能覆盖同名文件 | 文件路径直接拼Shell参数，固定临时文件名 | 每次独立目录，环境变量引用传路径，失败收尾明确 | TUI真实外部编辑器脚本与写失败清理回归 |
| 未结束粘贴可无限累积，拒绝提示却误称历史满 | 仅在结束时检查归档预算，错误提示不区分原因 | 在途单段也有32MiB上限，区分单段/会话提示 | TUI未闭合超大粘贴后仍可插入小段回归；ADR-0023 |
| CLI错误页、文件候选仍能送入方向控制字符；PNG坏像素被画成白色 | 非统一展示出口绕过转义；调色板越界被兜底掩盖 | 统一转义并补方向控制范围，实际索引越界拒绝 | CLI/TUI控制字符和候选宽度测试，合法CRC畸形PNG回归 |

评测检查器的五个漏检与上游dotenv模板转义缺陷仍保留，不能把“初始会失败”或“测试进程成功退出”当成需求覆盖证明。后续加强评测应建立新基线；上游模板应复制为自己的技能后修复，详见 Workspace/评测报告。
